## 📋 Descripción
Esta es la primera fase del proyecto de Seguridad Ciudadana. Consiste en una herramienta de emergencia diseñada bajo el principio de "un toque". Su objetivo es garantizar velocidad y simplicidad.

### Funcionalidades Principales
*   **Botón SOS:** Interfaz minimalista centrada en un botón grande y accesible.
*   **Prevención de Falsos Positivos:** Lógica de "Long Press" (Mantener presionado 3 segundos) para activar.
*   **Simulación de Emergencia:** Pantalla de "Ayuda en Camino" y opción de cancelación segura.
